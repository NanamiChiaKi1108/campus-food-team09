# 今天吃什么 · 最终项目源码（1.3.1）

平时请从上一级目录双击“开始体验.cmd”，或阅读本目录的“docs/项目报告.md”。本目录是唯一保留的项目源码。

| 目录或文件 | 用途 |
| --- | --- |
| demo/ | 可直接打开的浏览器演示，内部脚本、样式和图片都是运行依赖 |
| miniprogram/ | 原生微信小程序源码与共享业务规则 |
| cloudfunctions/ | 微信云函数及数据库、存储权限规则 |
| docs/项目报告.md | 最终报告可编辑源稿 |
| docs/需求分析.md | 完整需求章节 |
| docs/微信部署.md | 微信环境配置步骤 |
| docs/功能验收表.md | 当前功能验收清单 |
| docs/分工与答辩.md | 四人功能责任与答辩步骤 |
| docs/设计说明.md | 数据、算法、权限与容量边界 |
| docs/需求完善说明.md | 当前功能细节与验收示例 |
| docs/测试记录.md | 当前验证范围，原始测试输出和最终截图位于同目录 |
| tests/、tools/ | 自动回归、检查、共享规则同步、预览服务及报告生成工具 |
| project.config.json | 微信开发者工具导入入口 |

已配置五餐厅、10个示例窗口、30道示例菜品；170项自动回归通过。真实微信登录、云共享、安全审核、订阅收信与真机兼容仍需使用自己的AppID和云环境实测。

开发命令：`npm test`、`npm run check`、`npm start`，均无需安装第三方npm依赖。也可以双击“运行测试.cmd”。HTTP预览只监听本机127.0.0.1:4173。

修改共享规则后执行 `node tools/sync-core.cjs`，再运行测试。报告源稿位于docs/项目报告.md，tools/build-report.py需要Python、ReportLab与微软雅黑字体，输出上一级目录的PDF报告。
