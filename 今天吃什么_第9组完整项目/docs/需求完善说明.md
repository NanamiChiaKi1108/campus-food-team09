## 立即运行

1. 在本项目目录双击“一键演示.cmd”，或打开 demo/index.html。浏览器演示无需安装依赖。
2. 到“我的食光”使用体验身份登录，再到“口味与提醒”设置荤素、辣度、忌口。
3. 首页选择条件，点击“应用口味画像”，再打开转盘；结果可以进入菜品详情或加入就餐日历。
4. 管理台点击“进入演示管理台”，完成评价审核和目录维护。此权限仅用于本机演示。
5. 有 Node.js 时执行 npm test 与 npm run check；运行测试.cmd 也会执行完整测试。npm start 提供 http://127.0.0.1:4173/demo/index.html 本机预览。

微信开发者工具应导入包含 project.config.json 的内层项目目录。微信接入步骤见[微信部署.md](微信部署.md)。不需要在浏览器中填写微信账号。
