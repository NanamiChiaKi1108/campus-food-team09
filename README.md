# 今天吃什么

HTML5移动应用开发课程第9组项目，提供浏览器演示、原生微信小程序、微信云函数及课程文档。

## 快速体验

1. 点击 GitHub 的 **Code → Download ZIP**，完整解压。
2. 在解压后的最外层双击 **开始体验.cmd**，自动使用已安装的 Edge 或 Chrome 打开演示，无需安装依赖或填写微信账号。
3. 进入“我的食光”，点击“使用体验身份登录”。按[使用说明](使用说明.txt)体验筛选转盘、食堂目录、拥挤度、评价收藏和管理审核。
4. 电脑端点击“管理工作台 → 进入演示管理台”，可直接体验审核与目录维护，无需管理员密码。

请保持整个目录结构完整，不要只下载一个HTML文件或启动文件运行。

## 功能与验证

覆盖基础园餐厅、湖畔餐厅、翔远餐厅、鸿鹄餐厅、莘子园餐厅，配置10个示例窗口与30道示例菜品。支持组合筛选、转盘推荐、口味画像、拥挤度上报、图文评价、收藏、排行榜、积分勋章及内容管理；保留菜品对比、就餐计划和预算打卡。

170项自动测试及静态检查通过。需要复现时，进入内层项目目录执行 `npm test`、`npm run check`，或双击该目录中的“运行测试.cmd”。

## 使用范围

窗口、菜品、价格和初始记录为课程演示资料，位置、楼层与营业时间待核实。浏览器数据保存在当前浏览器，不同设备之间不共享。真实微信登录、云共享、内容安全、订阅消息及真机适配需配置自己的AppID和云环境后实测，当前未发布线上小程序。
