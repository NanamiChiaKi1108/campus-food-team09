《今天吃什么》使用说明（教师阅览）
第9组课程项目 · 最终版 1.3.1

一、快速打开

1. 如果收到的是压缩包，请先完整解压，再打开解压后的文件夹。
2. 双击最外层的“开始体验.cmd”，系统将自动使用已安装的 Edge 或 Chrome 打开演示页面。
3. 建议使用 Windows 电脑及 Edge 或 Chrome 浏览器。
   浏览器演示无需安装依赖、无需启动服务器，也无需微信账号。
4. 如果快捷入口没有打开，请进入：
   今天吃什么_第9组完整项目 → demo → index.html
   右键 index.html，选择“打开方式”，使用 Edge 或 Chrome 打开。

注意：请保持整个文件夹结构完整，不要只取出 HTML 文件或快捷入口运行。
无需打开 localhost 地址，也无需在命令行中输入命令。

二、登录体验身份

进入“我的食光”，点击“使用体验身份登录”。
此为本地演示身份，无需填写账号和密码。登录后可收藏、评价、上报和投票。
未登录时也可浏览食堂、筛选菜品和使用转盘推荐。

三、建议体验顺序（约5至8分钟）

1. 浏览餐厅与菜品
   点击“食堂地图”，可切换基础园餐厅、湖畔餐厅、翔远餐厅、
   鸿鹄餐厅、莘子园餐厅。点击“查看窗口”进入窗口，再点击菜品查看详情。

2. 筛选与转盘推荐
   进入“发现美味”，选择食堂、预算、口味、辣度和荤素等条件。
   示例：莘子园餐厅、15元以内、纯素、不辣。
   点击“帮我选一餐”，在弹出的转盘中开始推荐。
   转盘只从满足当前条件的在售菜品中选择，结果可进入菜品详情。
   若无匹配菜品，可减少条件或点击“清空筛选”。

3. 收藏与评价
   登录后，在菜品详情中收藏菜品，选择星级并填写评价；图片可选。
   评价示例：“口味清淡，分量合适，整体体验不错。”
   提交后显示“待审核”，不会立即作为公开评价计入平均分。
   窗口也可单独收藏。

4. 上报排队情况
   进入“排队实况”，对食堂或窗口选择“较空闲”“需等待”或“较拥挤”。
   提交后可查看更新结果。同一地点一分钟内不能重复上报。
   上报有效期为15分钟；显示“暂无上报”表示缺少近期数据。

5. 查看榜单与个人记录
   “人气榜单”可查看人气菜品、好评窗口和拥挤度榜，登录后可投票。
   “我的食光”可查看我的收藏、我的评价、我的上报及积分勋章。
   在“口味与提醒”中可设置偏好和忌口；返回首页后点击“应用口味画像”使用。

6. 体验辅助功能（可选）
   菜品卡片可加入对比，最多同时比较3道菜。
   “就餐日历”可安排午晚餐、记录实际花费、查看周预算和花费统计。
   花费由用户手工填写，不涉及支付。

四、管理端体验

1. 电脑端点击左侧“管理工作台”；较窄页面可使用页底的管理入口。
2. 点击“进入演示管理台”，无需管理员账号或密码。
3. 在“评价审核”中找到刚提交的评价，点击“审核通过”。
   再回到菜品详情或个人中心，可查看公开评价、评分及积分变化。
4. 管理台还可维护食堂、窗口、菜品，调整价格和上下架状态，处理举报，
   并查看数据概览和操作记录。

上述入口仅用于本地演示。真实微信云模式的管理员权限由服务端白名单控制。

五、提交文件说明

开始体验.cmd：浏览器演示的启动入口。
成绩评定表.docx：本组成绩评定材料，成绩栏由老师填写。
使用说明.txt：本说明文件。
今天吃什么_第9组完整项目：完整项目文件夹，包含演示、小程序源码、
云函数、可编辑报告、部署说明及测试文件，演示时不必逐个打开。
完整项目报告见该文件夹中的 docs\项目报告.md。

如需检查微信小程序源码，请在微信开发者工具中导入内层
“今天吃什么_第9组完整项目”文件夹，即包含 project.config.json 的目录。
具体配置步骤见该目录下的 docs\微信部署.md。

六、演示范围与数据说明

1. 五个餐厅名称按需求配置；窗口、菜品、价格及初始记录为课程示例。
   实际位置、楼层和营业时间仍需核实，拥挤度仅供参考。
2. 演示记录保存在当前浏览器中，不同电脑或浏览器之间不互通。
   建议使用普通浏览窗口，并始终从同一解压目录打开。
3. 浏览器中的登录和管理权限为体验模式；饭点提醒只保存选择，不发送消息。
   真实微信登录、云共享、内容安全审核及订阅收信，需要配置自己的
   AppID、云环境和模板后另行验证。当前提交未发布为线上小程序。
4. 本项目不包含支付、外卖配送或陌生人社交功能。
5. 最终版本已通过170项自动测试及静态检查；浏览器显示检查不能替代
   微信开发者工具编译和微信真机测试。
